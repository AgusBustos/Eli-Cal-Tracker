Conexión de Base de Datos Pendiente

No pudimos establecer conexión con la base de datos PostgreSQL. Para comenzar a usar el Tracker Académico, por favor inicializa la base de datos.

Intentando Conectar con:

  • Host {{ config.host }}
  • Puerto {{ config.port }}
  • Base de Datos {{ config.database }}
  • Usuario {{ config.user }}

Paso 1: Crear la Base de Datos e importar el esquema

Ejecuta el siguiente comando en tu terminal para crear la base de datos y cargar la estructura inicial:

psql -h {{ config.host }} -U {{ config.user }} -d postgres -c "CREATE DATABASE {{ config.database }};"
psql -h {{ config.host }} -U {{ config.user }} -d {{ config.database }} -f database.sql

Paso 2: Configurar credenciales customizadas (Opcional)

Puedes crear un archivo .env en la raíz del proyecto para definir tus credenciales:

DB_HOST=localhost
DB_PORT=5432
DB_NAME=tracker_universitario
DB_USER=tu_usuario_postgres
DB_PASSWORD=tu_contraseña
